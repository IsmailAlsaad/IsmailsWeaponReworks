This mod is meant to be played with **"Factorraria"** which is a factory automation mod, but it can still be played standalone

It doesn't add any new weapons
Instead it aims to spice up the vanilla weapons by giving them new mechanics and visuals
as well as redesigning the progression

The mod is currently in beta stage and only cover ***pre-hm*** content

#### list of done weapon reworks:

**Melee:**
all broadswords
all shortswords
all flails
all yoyos
all spears
all boomerangs
